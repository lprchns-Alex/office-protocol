# OFFICE_PROTOCOL

Мобильная игра про офисный кринж. React Native + Expo SDK 57 + TypeScript. Интерфейс на русском, чёрный и кислотно-салатовый, бинго 3×3.

## Запуск

```sh
npm install
npm start
```

На телефоне: откройте Expo Go, совместимый с SDK 57, и подключитесь к адресу `exp://<IP-компьютера>:8081`. Телефон и компьютер должны быть в одной сети. Сборка для магазинов и подпись сертификатами пока не настроены.

Превью в браузере: `npm run web`, затем http://localhost:8081.

На этом Mac превышен лимит файловых наблюдателей Metro, поэтому команды `start` и `web` используют CI-режим: автоперезагрузка отключена. После изменения исходников перезапустите сервер и обновите страницу. С установленным Watchman доступен обычный режим `npm run dev`.

## Что работает

- Бинго 3×3 с общим набором из 30 карточек и отдельным прогрессом каждого манагера.
- Четыре вымышленных персонажа, досье, статистика по категориям, шуточная совместимость.
- Подтверждение событий; 50–200 очков за карточку; 300 за каждую новую строку, колонку или диагональ; новый уровень каждые 1000 очков.
- Замена только неотмеченных карточек; новая смена после полного заполнения с сохранением очков.
- Добавление и редактирование карточек и манагеров в режиме локального администратора.
- Сохранение через AsyncStorage, восстановление после перезапуска, последовательная запись изменений.
- Рапорт с визуальным оформлением и отправкой текстового отчёта через системное меню. В браузере без Web Share используется копирование текста.
- Тактильный отклик на устройствах, анимированное бинго, подтверждение перед сбросом прогресса.

Режим администратора — локальное переключение инструментов, а не защищённая учётная запись. Сервер, авторизация и синхронизация не входят в эту версию. При удалении приложения локальные данные теряются. Рапорт пока отправляется текстом, не картинкой.

## Проверки

```sh
npm test
npm run typecheck
npx expo install --check
npm run export
```

Экспорт создаёт JS/Hermes-бандлы Android и iOS и браузерное превью. Это не подписанные APK/IPA. Для нативной сборки используйте совместимое окружение Android Studio/Xcode или EAS после настройки аккаунта.

## Структура

- `App.tsx` — экраны, навигация, модальные окна, сохранение.
- `src/game.ts` — данные и чистые функции игровой механики.
- `src/ui.tsx` — палитра, стили, общие элементы и иконки Lucide.
- `tests/game.test.mjs` — проверки начисления очков, линий, смены и сохранения.
- `assets/protocol-icon.svg` — исходник иконки; `npm run assets` обновляет PNG.
