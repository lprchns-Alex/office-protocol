# Портреты OFFICE_PROTOCOL

Четыре оригинальных вымышленных персонажа. Созданы встроенным image_gen (режим generate, не CLI). Референсы пользователя использованы как направление для зернистой монохромной стилистики, не для копирования личности. PNG — исходники; JPG 640×640 — оптимизированные файлы приложения, без дополнительной стилизации.

## Общий промпт

Use case: stylized-concept
Asset type: square portrait photo asset for a fictional character dossier in the mobile cyberpunk game OFFICE_PROTOCOL.
Primary request: create one original fictional office-manager portrait, rendered like a gritty low-resolution corporate surveillance ID scan.
Scene/backdrop: plain charcoal background with faint coarse photocopy texture.
Style/medium: photographic anatomy and clothing, converted to bold black-and-white halftone / ordered-dither print with visibly crunchy dots and fine horizontal scanlines. Strong readable face, not a cartoon, not a painting. Subtle cool gray-green tint, near-monochrome. Underground retro computer terminal aesthetic.
Composition: square, centered head-and-shoulders, entire hair visible with small top margin, face taking about half image height, looking into camera, uncluttered silhouette. Keep eyes sharp and readable at small mobile thumbnail size.
Lighting: hard side light, deep blacks, silver highlights, moody but face clearly legible.
Constraints: one adult fictional person, no resemblance to reference people required, no letters, no typography, no numbers, no logos, no watermark, no borders, no UI, no collage, no neon city background.
